# Atividade de POO em Java

Projeto desenvolvido durante os estudos de **Programação Orientada a Objetos (POO)**, utilizando a linguagem Java.

## Objetivo

Praticar os principais conceitos da programação orientada a objetos por meio da implementação de classes, objetos e métodos.

## Conceitos praticados

- **Classes e objetos:** criação e utilização de classes para representar elementos do sistema.
- **Encapsulamento:** utilização de atributos privados e métodos de acesso.
- **Referências de objetos:** atribuição de referências e compartilhamento de objetos.
- **Métodos:** implementação de ações e comportamentos das classes.
- **Atributos estáticos (`static`):** contagem de objetos instanciados.
- **Tratamento de referências nulas (`null`):** verificação da existência de objetos.
- **Pacotes (`package`):** organização das classes em diferentes pacotes.
- **Composição:** associação entre motorista e carro.
- **Garagem:** armazenamento e exibição de até três carros.
